## Logo Guidelines

- **Format:** PNG with transparent background preferred
- **Size:** Recommended 200x200px or similar square format
- **Quality:** High resolution for retina displays
- **Naming:** Use lowercase with hyphens (kebab-case)

## How to Add Logos

1. Download logos from client websites or request from clients
2. Resize to consistent dimensions (e.g., 200x200px)
3. Save as PNG with transparent background
4. Place in this folder with appropriate filename

## Fallback

If logos are not available, the current emoji icons will be used as placeholders.
