# A-Team Clean Gebäudereinigung Website

Modern, high-performance website for A-Team Clean professional cleaning services built with React, Vite, and Tailwind CSS.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Tech Stack

- **Framework:** Vite + React 18
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **SEO:** Optimized meta tags, sitemap, robots.txt

## 🌟 Features

- ✅ Modern, responsive design (mobile-first)
- ✅ Video hero header with smooth animations
- ✅ Service showcase with 6 main offerings
- ✅ Contact form with email integration
- ✅ SEO optimized (meta tags, semantic HTML)
- ✅ Fast loading times (<3s)
- ✅ Accessibility features (ARIA labels, keyboard navigation)

## 🚢 Deployment to Vercel

### Option 1: Vercel CLI
```bash
npm install -g vercel
vercel
```

### Option 2: GitHub Integration
1. Push code to GitHub
2. Import repository in Vercel dashboard
3. Deploy automatically

### Option 3: Manual Deploy
```bash
npm run build
vercel --prod
```
